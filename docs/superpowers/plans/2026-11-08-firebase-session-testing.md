## 검증

1. `pnpm vitest run packages/firebase-session` — 새 시험과 기존 시험 모두 통과(기존 시험 파일은 고치지 않음).
2. `pnpm run verify` — lint·format·typecheck·test·build·check:package(publint·attw가 새 진입점 포함)·size.
3. `pnpm build && pnpm compat` — 두 fixture에서 새 진입점 타입 검사.
4. `grep -r "testing" packages/firebase-session/dist/worker packages/firebase-session/dist/client` 결과 없음(운영 진입점이 새 코드를 끌어오지 않음).
